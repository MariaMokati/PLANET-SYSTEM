# docs

| File | What it is |
|---|---|
| `heikin_ashi_guide.pdf` | Reading the chart with Heikin Ashi candles — the guide. 26 pages. |
| `heikin_ashi_guide.html` | The source the PDF is rendered from. |
| `build_heikin_ashi_guide.py` | Regenerates the HTML. All content lives in this file. |

## Rebuilding

```sh
OUT=docs/heikin_ashi_guide.html python3 docs/build_heikin_ashi_guide.py
chrome --headless --no-pdf-header-footer \
  --print-to-pdf=docs/heikin_ashi_guide.pdf docs/heikin_ashi_guide.html
```

Every candle drawing is an inline SVG generated by `chart()` — there are no image
files and no external assets, so the HTML opens correctly on its own.
